# Meridiana Cafe Dashboard

> Dashboard and menu generator for Meridiana Cafe.

Questo progetto contiene template e script per generare i menu e le pagine giornaliere/settimanali del Meridiana Cafe.

Contenuto principale:
- file HTML di dashboard e template
- script in `crea-menu/` per generare i menu

Come usare (veloce):
1. Esplora la cartella `crea-menu` per i tool di generazione.
2. Apri `dashboard.html` o `template_giornaliero.html` nel browser per vedere i risultati.

Ho eseguito un fetch/merge dal repository remoto indicato e ho aggiunto questo `README.md` localmente.

Se vuoi, posso anche committare e pushare il `README.md` sul repository remoto: dimmi se vuoi che lo faccia.
